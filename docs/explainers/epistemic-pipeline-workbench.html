3. The Seven Anti-Collapse Axioms (CEP-0008 §53) Epistemological Invariants
Explore the 7 structural traps where AI developer tools fail, and how SXR prevents each collapse.
Axiom 1 / 7

Data Is Not Evidence

Raw observations possess zero semantic truth. They merely report what a process printed. An observation only becomes evidence through explicit, question-bound derivation.

✗ Naive Tool Trap

A test runner prints "Passed 4 tests". The agent immediately concludes: "Feature X is fully proven and works correctly in production."

✓ SXR Structural Protection

Process output is quarantined in observation.recorded. To become evidence, it must declare question_ref, relevance, reliability, and direction (supports/contradicts).
