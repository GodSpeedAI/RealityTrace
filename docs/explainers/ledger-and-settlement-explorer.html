Cryptographic Append-Only Ledger & Settlement Explorer

In SXR, raw execution output is not proof, and process exit code 0 is not settlement. Every event is committed to a dense, gapless SHA-256 hash chain in SQLite (ledger.db), where each record binds its predecessor's digest ($h_n = \text{SHA256}(\text{canonical}(\text{row}_n))$). Explore the live cryptographic chain, test how tamper-evidence breaks downstream links, and observe how threshold algebra determines formal settlement.
